# Resumo — Aula 01: Apresentação da Disciplina e Contextualização

## Objetivo da aula
A primeira aula apresentou a disciplina de **Frameworks Front-end**, sua organização, metodologia, critérios de avaliação e uma visão geral dos conteúdos que serão estudados ao longo do semestre.

## Contexto da disciplina
- Frameworks Front-end são fundamentais no desenvolvimento web moderno.
- O front-end é a camada da aplicação com a qual o usuário interage, sendo responsável pela interface, experiência do usuário e comunicação com o back-end.
- Empresas buscam interfaces rápidas, organizadas e de fácil manutenção.

## Conteúdos do semestre
- HTML, CSS e JavaScript (Vanilla JS)
- Versionamento com Git e GitHub
- Deploy de aplicações (Vercel)
- Frameworks Front-end (React, Vue e Angular)
- Componentização
- Gerenciamento de estado
- Rotas
- Integração com APIs
- Boas práticas de desenvolvimento

## Objetivos de aprendizagem
Ao final da disciplina o aluno deverá ser capaz de:
- Desenvolver interfaces modernas.
- Criar aplicações utilizando Frameworks Front-end.
- Utilizar Git e GitHub.
- Publicar aplicações na Web.

## Metodologia
- Aulas expositivas dialogadas.
- Discussões e estudos de caso.
- Integração entre teoria e prática.
- Desenvolvimento de projetos em grupo.

## Avaliação
- 55% Avaliação docente:
  - 20% Desenvolvimento do projeto
  - 20% Apresentação
  - 15% Atividades
- 35% Projeto Integrador
- 10% Autoavaliação

## Projeto da disciplina
O projeto final deverá ser documentado como um mini TCC, contendo planejamento, desenvolvimento, desafios, soluções e resultados.

## Atividades iniciais
1. Criar um projeto utilizando HTML, CSS e JavaScript.
2. Configurar GitHub e realizar o deploy na Vercel.
3. Formar grupos de 3 a 5 integrantes.
4. Criar um repositório GitHub.
5. Elaborar um resumo da Aula 01 em Markdown.
6. Produzir um relatório técnico sobre um Framework Front-end.

## Conclusão
A aula teve caráter introdutório e mostrou a importância dos Frameworks Front-end no mercado, além de apresentar toda a organização da disciplina, os critérios de avaliação e as atividades que serão desenvolvidas durante o semestre.
