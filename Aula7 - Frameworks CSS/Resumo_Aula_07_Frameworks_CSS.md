# Resumo — Aula 07: Frameworks CSS

## Objetivo da aula
A aula 07 apresentou os frameworks CSS, que são ferramentas que ajudam no desenvolvimento de interfaces web com mais rapidez, padronização e organização visual.

## O que são frameworks CSS
Frameworks CSS são bibliotecas ou estruturas prontas que oferecem estilos e componentes reutilizáveis para facilitar a criação de layouts e interfaces.

Esses frameworks ajudam a:
- acelerar o desenvolvimento
- padronizar a aparência da aplicação
- reutilizar classes e componentes
- melhorar a responsividade
- reduzir a quantidade de código manual

## Vantagens do uso
Entre as principais vantagens, destacam-se:
- produtividade maior
- design mais consistente
- componentes prontos como botões, formulários e grids
- facilidade de criar layouts responsivos
- organização visual em projetos maiores

## Exemplos de frameworks CSS
Alguns frameworks muito conhecidos incluem:
- Bootstrap
- Tailwind CSS
- Foundation
- Bulma

Cada um tem suas próprias características, mas todos ajudam a criar interfaces mais rapidamente.

## Importância do CSS básico
Mesmo usando frameworks, é fundamental conhecer CSS básico, porque:
- ajuda a entender como os estilos funcionam
- permite personalizar melhor a interface
- facilita a adaptação do framework ao projeto
- evita depender totalmente de classes prontas

## Design e consistência
Os frameworks também ajudam a criar uma identidade visual mais consistente entre páginas e elementos, como:
- espaçamento uniforme
- cores padronizadas
- tipografia organizada
- componentes com aparência semelhante

## Conclusão
A Aula 07 mostrou que os frameworks CSS são ferramentas muito úteis para desenvolver interfaces modernas de forma ágil e padronizada. Porém, o conhecimento de CSS básico continua sendo essencial para personalizar, ajustar e compreender melhor o funcionamento dos estilos no projeto.
