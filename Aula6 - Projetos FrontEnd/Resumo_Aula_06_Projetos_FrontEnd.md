# Resumo — Aula 06: Projetos Front-End

## Objetivo da aula
A aula 06 teve como foco a prática de desenvolvimento de projetos front-end, mostrando que criar uma interface não é apenas escrever HTML, CSS e JavaScript, mas também planejar, estruturá-la e entregar uma solução funcional.

## Conceito principal
Projetos front-end envolvem a criação de interfaces que atendam às necessidades do usuário e que sejam fáceis de usar, visualmente agradáveis e bem organizadas.

## Principais temas abordados
- Definição do objetivo do projeto
- Levantamento de requisitos
- Entendimento do público-alvo e do problema a ser resolvido
- Organização da estrutura do projeto
- Criação de layouts responsivos e intuitivos
- Integração com APIs e dados dinâmicos
- Desenvolvimento de funcionalidades essenciais
- Testes e validação do projeto
- Publicação e deploy da aplicação

## Importância de planejar antes de programar
Antes de iniciar a codificação, é importante responder perguntas como:
- Qual problema o projeto resolve?
- Quem vai usar a aplicação?
- Quais funcionalidades são indispensáveis?
- Como a interface deve funcionar em diferentes telas?

Esses cuidados ajudam a evitar retrabalho e tornam o desenvolvimento mais eficiente.

## Organização do projeto
Um projeto front-end bem estruturado costuma ter:
- pastas para componentes
- arquivos de estilo
- scripts e lógica
- imagens e assets
- documentação ou anotações

Essa organização facilita a manutenção, a colaboração em equipe e a escalabilidade do código.

## Experiência do usuário
A aula também enfatizou que o front-end deve priorizar a experiência do usuário, com:
- boa navegação
- design limpo
- texto legível
- botões e ações claras
- responsividade em celulares, tablets e desktops

## Integração com APIs
Em muitos projetos, o front-end precisa consumir dados de uma API. Isso permite:
- buscar informações em tempo real
- exibir conteúdos dinâmicos
- interagir com sistemas externos
- criar aplicações mais úteis e modernas

## Conclusão
A Aula 06 mostrou que um projeto front-end exige mais do que visual bonito: é preciso ter planejamento, boa arquitetura, foco em usabilidade e capacidade de transformar uma ideia em uma aplicação funcional e bem estruturada.
