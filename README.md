# 📚 Frameworks Front-end

> Repositório dedicado aos estudos da disciplina de **Frameworks Front-end** do SENAI.

## 📖 Sobre

Este repositório reúne todo o material desenvolvido durante a disciplina, incluindo:

- 📝 Resumos das aulas em Markdown
- 💻 Exercícios práticos
- 🚀 Projetos desenvolvidos durante o semestre
- 📂 Exemplos de código
- 📚 Anotações e materiais de apoio

O objetivo é centralizar todo o conteúdo da disciplina em um único lugar, facilitando consultas futuras e acompanhando a evolução do aprendizado.
